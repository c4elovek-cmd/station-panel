Сказать на колонке

Вход по SSH (порт 2222), пользователь root, пароль пустой. CLI yam в сборке демона нет — команды YAM дублируют HTTP API для удобства.

Файлы колонки

Пакеты YAM

Реестр пакетов — yapkg. Установить можно из реестра вручную (yam install <id>) или загрузить файл .yap.

Настройки плагина

Настройки — JSON-объект для плагина. Если манифест содержит settings, поля и значения по умолчанию будут показаны автоматически.

Редактировать JSON вручную

Установка из реестра

Ставится последняя версия из реестра yapkg по SSH. Для бинарных пакетов включи «Разрешить бинарники плагинов» в разделе «Система».
