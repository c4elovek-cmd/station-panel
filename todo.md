# Панель Станции — задачи

Обновлено: 28.10.2026. Отметки: ☑ сделано · ◐ частично · ☐ не сделано.

## Запросы пользователя

- ☑ **Громкость колонки в панели** — слайдер громкости самой колонки (общий регулятор ALSA Master через `amixer`, шкала 0..100 %) в «Обзоре», GET/PUT `/api/volume`, опрос раз в 30 с, во время drag'а не дёргается. Ранее: слайдер громкости Spotify (spotiya). Осталось (по желанию): громкость для других источников (soundya, локальный плеер).
- ☐ **Профиль подсветки подбирается сам** — детектить модель колонки (по `/api/device` или `/proc/device-tree`) и выбирать LED-профиль YAM автоматически, без ручного выбора во вкладке «Система».
- ◐ **Панель для других людей: объяснения и инструкции** — README есть, инструкции есть в «Мастере настройки» (что делает каждый шаг, что делать после), в «Голосовых командах» и «Телеметрии»; автонастройка объяснена в панели. Осталось: пройтись по остальным вкладкам и добавить маленькие описания «что это и как пользоваться» для новичков без root-опыта.
- ☑ **Фотки/картинок колонок** — скачаны официальные фото всех 12 моделей со страниц Справки Алисы (`static/img/speakers/*.png`), подставляются по модели в «Обзоре» (`MODEL_PHOTOS`), фолбэк на SVG; под фото — компактные характеристики модели (`MODEL_SPECS`). Источники: alice.yandex.ru/support/.../characteristics-*, hackalice.me/devices/.
- ☑ **Кастомное время не должно сбрасываться на колонке** — закрепление времени через `POST /api/clock/pin` (фоновый цикл панели переподтверждает каждые 5 с), чекбокс «Закрепить это время», кнопка «Сейчас» снимает закрепление всегда.
- ◐ **Плавные графики датчиков** — тултип по курсору уже следует за движением (`mousemove`/`mouseleave` в app.js). Осталось: интерполяция между точками, чтобы линия/курсор двигались плавно, а не прыгали по точкам данных.
- ☐ **Музыка: показывать только установленные сервисы** — во вкладке музыки показывать не все сервисы сразу, а только те, что пользователь скачал и выбрал (по факту наличия пакета на колонке: soundya/spotiya/soloist).
- ☑ **Отключение телеметрии** — панель «Телеметрия Яндекса» в «Системе»: убирает `telemetry` и `fluent-bitd` из `servicesList` в `/system/vendor/quasar/quasar.cfg` (remount rw → бэкап `quasar.cfg.bak-panel` → правка → remount ro), включение восстанавливает бэкап байт-в-байт. С честным предупреждением: применяется после перезагрузки, Яндекс может перезаписать конфиг при обновлении прошивки. Проверено на живой колонке (отключение → включение → идентичен оригиналу).
- ☐ **Развёртывание панели через Home Assistant** — оценить реализуемость: аддон/контейнер HA (config через опции аддона), чтобы панель поднималась как дополнение к HA. Сначала спел-чек, потом решение.

## Готово в v2.0.0

- ☑ **Редизайн по референсу Dribbble «SIERE»** — винная тема (`#ec7a8e`), radial-фон, градиентные nav/карточки, токены `:root`; структура классов и логика не тронуты.
- ☑ **Вкладка «Внешний вид»** — тема (Ночь/День), 6 курсоров, 5 шрифтов (Google Fonts с fallback), тумблер liquid-glass стекла; настройки в localStorage браузера, раннее применение в `<head>` без мигания. Дальше сюда же — новые функции внешнего вида.
- ☑ **Liquid-glass кружок за курсором** — декоративный (`pointer-events:none`), гасится на тач-устройствах и при `prefers-reduced-motion`, выключается тумблером.
- ☑ **Красивое имя модели** — «Яндекс Станция Мини 2 с часами» вместо `yandexmini_2` в сайдбаре, карточке и title (`MODEL_NAMES`/`CLOCK_MODELS`/`prettyModel`).
- ☑ **Мастер настройки** — одна кнопка в «Системе»: связь → станция → LED-часы → громкость → голосовой мост → слово активации → телеметрия → итог; ошибки шагов не прерывают прогон, есть инструкция. Протестирован на живой колонке.
- ☑ **Громкость колонки** — см. выше.
- ☑ **Телеметрия Яндекса** — см. выше.
- ☑ **Фото и характеристики 12 моделей** — см. выше.
- ☑ **Фикс `start.ps1`/`stop.ps1` для чужих машин** — UTF-8 BOM: Windows PowerShell 5.1 читала файлы без BOM как ANSI и ломала парсер («нет завершающего символ '»).
- ☑ **Вкладка «Слова»** — обучение wake-word через прокси к демону :8780 (master записи, список слов, чувствительность, срабатывания, «ложное», прослушивание записей) — коммит `eb21501`.
- ☑ **Автонастройка сервера** (коммит `3b8cacf`): автодетект IP станции (скан подсети), подбор порта YAM (8099/8080/80) и SSH (2222/22), генерация ed25519-ключа панели и установка его на колонку, проверка входа по ключу, проверка SFTP (с честным объяснением про dropbear). Ключ в `keys/`, в `.gitignore`. Проверено на живой колонке.
- ☑ **Панель запущена**: http://127.0.0.1:8787 (рестарт `.\start.ps1 -Restart`).

## Идеи из вики (hackalice.me) — кандидаты на следующие версии

1. Редактор LED-анимаций (свои эффекты, не только пресеты).
2. Дакинг музыки при голосовой команде (приглушение фоном).
3. Аудит безопасности: проверка открытых портов 8099/2222 и рекомендации.
4. Замена системных звуков (восклицание/щелчки) на свои.
5. Автоподбор LED-профиля по модели (см. задачу выше).
6. Умный дом без интернета (Matter/Zigbee через колонку).
7. Замена голоса Алисы (свой TTS на колонке).
8. Свои пробуждения/секвенции (activation_feedback_player в quasar.cfg).
9. Скринсейвер-часы на всю ночь (яркость по времени суток).
10. Логи падений/минидампов в панели (читать `${LOGS}` без SSH).
