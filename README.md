# Панель Станции

Веб-панель для Яндекс Станции (Мини 2, Лайт, Лайт 2 и другие модели с root):
управление подсветкой, LED-часами, плагинами YAM, SSH-терминал в браузере и датчики.

## Возможности

- **Обзор** — статус колонки, возможности устройства, быстрые команды;
- **Терминал** — SSH-терминал прямо в браузере (WebSocket + pty, xterm.js);
- **Пакеты** — менеджер YAM: список, установка `.yap`, запуск/остановка;
- **Подсветка** — цвета каждого диода, пресеты, выключение
  (на моделях без LED-кольца, например Лайт, вкладка подсветки и часы скрываются автоматически);
- **Часы** — управление LED-часами: время, яркость, выключение;
- **Датчики** — освещённость и температура с графиком;
- **Система** — настройки подключения, профиля YAM, пароля, обновлений панели.

Панель сама умеет обновляться из GitHub: вкладка «Система» → «Обновления панели».

## Как работает

`server.py` (FastAPI) проксирует HTTP API демона [YAM](https://github.com/nyakokitsu/yam)
на колонке и ходит на неё по SSH (dropbear, порт 2222). Терминал — WebSocket
к pty через asyncssh.

Что нужно на колонке: root, SSH (dropbear/sshd) и демон YAM (`yamd`).
Порт по умолчанию — SSH 2222, API YAM 8099.

## Пошаговая установка

### Шаг 0. Что нужно

- ПК с Windows 10/11 (панель работает и на macOS/Linux, но скрипты запуска — для Windows);
- Python 3.11 или новее ([python.org/downloads](https://www.python.org/downloads/)) — при установке отметь «Add Python to PATH»;
- Яндекс Станция с root-доступом (для Мини 2 и Лайт гайды есть на 4pda/hackalice.me);
- SSH-сервер на колонке (dropbear) и демон [YAM](https://github.com/nyakokitsu/yam).

### Шаг 1. Установи YAM на колонку (если ещё нет)

На ПК:

```powershell
irm https://hackalice.me/install.ps1 | iex
```

Установщик сам найдёт колонку в сети и поставит `yamd` (веб-интерфейс демона на порту 8099). Параллельно ставится SSH (dropbear, порт 2222, пароль пустой, вход под root).

### Шаг 2. Скачай панель

```powershell
cd G:\          # или любой другой диск/папка
git clone https://github.com/c4elovek-cmd/station-panel.git
cd station-panel
```

Git не установлен? Скачай zip со страницы релизов и распакуй.

### Шаг 3. Поставь зависимости

```powershell
pip install -r requirements.txt
```

Понадобятся `ffmpeg` в PATH — проверь командой `ffmpeg -version`. Если его нет: `winget install Gyan.FFmpeg` и открой консоль заново.

### Шаг 4. Запусти панель

```powershell
.\start.ps1
```

Скрипт запустит сервер скрыто в фоне и напечатает адрес. При первом запуске пароль создаётся автоматически и лежит в `password.txt` рядом со скриптом.

### Шаг 5. Войди и настрой

1. Открой `http://127.0.0.1:8787`, введи пароль из `password.txt`;
2. Вкладка **«Система»** → «Подключение к колонке»: IP станции (если не знаешь — кнопка **«Найти колонку»** просканирует сеть), порты SSH 2222 и YAM 8099 обычно верные по умолчанию;
3. **Смени пароль** в том же разделе (поле «Пароль панели»).

### Шаг 6. Голосовые команды (опционально)

Вкладка **«Система»** → «Голосовые команды»: впиши фразы-триггеры (например `дипсик`), нажми **«Установить на колонку»**. После этого «Алиса, дипсик, …» перехватывается плагином и уходит на мост (`voice-bridge`, см. отдельный репозиторий).

### Шаг 7. Автозапуск панели (опционально)

```powershell
$action = New-ScheduledTaskAction -Execute "pwsh" -Argument "-NoProfile -WindowStyle Hidden -File `"G:\station-panel\start.ps1`""
Register-ScheduledTask -TaskName "StationPanel" -Trigger (New-ScheduledTaskTrigger -AtLogon) -Action $action
```

### Обновление панели

Вкладка **«Система»** → «Обновления панели»: **«Проверить»** сравнивает локальную версию с GitHub, **«Обновить сейчас»** делает `git pull`, ставит зависимости и перезапускается сама. Галочка «Автопроверка раз в сутки» — на заметку о новых версиях.

### Бэкапы колонки

Вкладка **«Файлы»** → «Бэкапы /data на ПК»: **«Сделать бэкап сейчас»** архивирует `/data` колонки (настройки, плагины, скрипты) и сохраняет архив на ПК. Восстановление — кнопкой у соответствующего архива. Внимание: `/data` на прошивке — симлинк на `/bkupgrade/data`, поэтому **удалять содержимое /bkupgrade нельзя** — это сброс к заводским. Файловый менеджер панели это знает и защищает системные пути.

## Быстрый старт (для тех, кто уже всё ставил)

Требуется Python 3.11+ и Windows/macOS/Linux.

```powershell
pip install -r requirements.txt
python server.py
# или на Windows:
.\start.ps1
```

На Linux (включая VPS) — одной командой, с systemd-автозапуском:

```sh
sudo sh deploy/install.sh
```

или просто `sh deploy/start.sh` из папки `deploy` (без systemd, сам держит процессы живыми).
Подробности — `deploy/README.md`.


Панель откроется на `http://127.0.0.1:8787`. Пароль создаётся при первом
запуске и лежит в `password.txt` рядом со скриптом (не публикуется).

## Конфигурация

Всё в `config.json` (создаётся автоматически, в репозиторий не попадает):
IP станции, порты SSH/YAM, пароль панели (соль + хеш), срок сессии.

## Голос и музыка на колонке

Панель управляет тремя «жителями» колонки:

- **wakeword** — своё слово активации («Джарвис», «Дипсик» — любое). После
  установки открой `http://<IP колонки>:8780`, запиши слово 6–15 раз и обучи —
  2–3 минуты прямо на станции.
- **soundya** — SoundCloud: голосовые команды, лайки, рекомендации. Там, где
  SoundCloud недоступен, пропиши прокси в `/data/opt/soundya/config.json`
  (`{"proxy": "socks5://..."}`).
- **spotiya** — Spotify Connect + AirPlay 2. Нужен Spotify Premium, вход по
  коду `spotify.com/pair` (`spotiya login` на колонке).

> ⚠️ **Не управляй Spotify голосом через Алису.** Известны случаи блокировки
> аккаунтов за нестандартные запросы. Пользуйся приложением Spotify (выбери
> колонку как устройство) или AirPlay — голосовой перехват у spotiya можно
> выключить: `spotiya voice off`.

Все ручки продублированы во вкладке **«Музыка»** панели: поиск и воспроизведение
SoundCloud, пауза/треки/громкость Spotify, статус AirPlay.

## Обновления панели

Вкладка «Система» → «Обновления панели»: «Проверить» сравнивает локальный
коммит с GitHub, «Обновить сейчас» делает `git pull --ff-only`, ставит
зависимости и перезапускает панель. Есть галочка «Автопроверка раз в сутки».

## Безопасность

- Панель слушает `0.0.0.0` — если доступ из сети не нужен, поменяйте
  `panel_host` на `127.0.0.1` в `config.json`;
- пароль хранится как хеш с солью, сессии — cookie с истечением;
- `config.json` и `password.txt` исключены из репозитория через `.gitignore`.
