# Панель Станции

Веб-панель для Яндекс Станции (Мини 2 и другие модели с root): управление
подсветкой, LED-часами, плагинами YAM, SSH-терминал в браузере и датчики.

## Возможности

- **Обзор** — статус колонки, возможности устройства, быстрые команды;
- **Терминал** — SSH-терминал прямо в браузере (WebSocket + pty, xterm.js);
- **Пакеты** — менеджер YAM: список, установка `.yap`, запуск/остановка;
- **Подсветка** — цвета каждого диода, пресеты, выключение;
- **Часы** — управление LED-часами: время, яркость, выключение;
- **Датчики** — освещённость и температура с графиком;
- **Система** — настройки подключения, профиля YAM, пароля, обновлений панели.

Панель сама умеет обновляться из GitHub: вкладка «Система» → «Обновления панели».

## Как работает

`server.py` (FastAPI) проксирует HTTP API демона [YAM](https://github.com/nyakokitsu/yam)
на колонке и ходит на неё по SSH (dropbear, порт 2222). Терминал — WebSocket
к pty через asyncssh.

Что нужно на колонке: root, SSH (dropbear/sshd) и демон YAM (`yamd`).
Порт по умолчанию — SSH 2222, API YAM 8099.

## Запуск

Требуется Python 3.11+ и Windows/macOS/Linux.

```powershell
pip install -r requirements.txt
python server.py
# или на Windows:
.\start.ps1
```

Панель откроется на `http://127.0.0.1:8787`. Пароль создаётся при первом
запуске и лежит в `password.txt` рядом со скриптом (не публикуется).

## Конфигурация

Всё в `config.json` (создаётся автоматически, в репозиторий не попадает):
IP станции, порты SSH/YAM, пароль панели (соль + хеш), срок сессии.

## Обновления панели

Вкладка «Система» → «Обновления панели»: «Проверить» сравнивает локальный
коммит с GitHub, «Обновить сейчас» делает `git pull --ff-only`, ставит
зависимости и перезапускает панель. Есть галочка «Автопроверка раз в сутки».

## Безопасность

- Панель слушает `0.0.0.0` — если доступ из сети не нужен, поменяйте
  `panel_host` на `127.0.0.1` в `config.json`;
- пароль хранится как хеш с солью, сессии — cookie с истечением;
- `config.json` и `password.txt` исключены из репозитория через `.gitignore`.
